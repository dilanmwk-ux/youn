Cara pakai

  1. 1

    Salin alamat

    Alamat dibuat otomatis saat halaman terbuka. Mau yang baru? Tekan Alamat baru.

  2. 2

    Pakai untuk mendaftar

    Tempel di formulir pendaftaran atau layanan lain yang tidak perlu tahu email aslimu.

  3. 3

    Baca di kotak masuk

    Email masuk muncul sendiri. Ketuk untuk membaca, hapus kalau sudah selesai.

Yang kamu dapat

Tanpa akun

Alamat langsung siap begitu halaman terbuka. Tidak ada formulir dan tidak ada password.

Kotak masuk otomatis

Email baru muncul sendiri dalam hitungan detik. Biarkan tab terbuka saat mendaftar di layanan lain.

Username sendiri

Mau alamat yang mudah diingat? Pilih username 3–20 karakter.

Isi email aman dibuka

Email tampil dalam bingkai terisolasi, jadi skrip dari pengirim tidak dijalankan.

API untuk developer

REST + JSON dengan API key. Cocok untuk skrip, bot, dan tes otomatis.

Pertanyaan umum

Apakah TempMail gratis?

Ya, dipakai tanpa biaya dan tanpa akun.

Berapa lama pesan disimpan?

Pesan hanya disimpan singkat. Jangan dipakai untuk data penting atau akun yang perlu kamu akses lagi.

Apakah aman untuk akun penting?

Tidak disarankan. Alamat sementara bisa hilang, jadi pakai email tetap untuk bank, kerja, atau akun yang butuh pemulihan.

Kenapa ada verifikasi captcha?

Untuk mencegah penyalahgunaan otomatis. Kalau captcha gagal, muat ulang halaman atau coba verifikasi alternatif.

Butuh otomatisasi?

Buat kotak masuk sementara dari kode lewat REST API. API key dibuat langsung di halaman dokumentasi.
