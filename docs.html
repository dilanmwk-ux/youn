API TempMail

Buat kotak masuk sementara dari skrip, bot, atau tes otomatis. Format REST + JSON, tanpa SDK. Kunci dibuat di halaman ini, tanpa daftar akun.

Autentikasi
Kirim header x-api-key di setiap permintaan. Batas 60 permintaan per menit per kunci.

AksiParameterFungsi

Isi respons diteruskan apa adanya dari penyedia email (Guerrilla Mail), jadi nilainya berbeda tiap permintaan dan bisa ada field tambahan. Nilai di bawah hanya contoh.

Respons galat
Setiap galat berbentuk { "error": "pesan" } dengan kode status HTTP yang sesuai.
StatusRespons JSONPenyebab


400{ "error": "a harus salah satu dari: new, set, inbox, read, del" }Parameter a salah atau kosong


401{ "error": "API key tidak valid" }Header x-api-key kosong atau salah


401{ "error": "API key sudah dicabut" }Key dicabut lewat admin


405{ "error": "Gunakan POST" }Membuat key harus dengan POST


429{ "error": "Batas 60 permintaan/menit" }Melewati batas per key


429{ "error": "Maksimal 5 kunci per jam" }Terlalu sering membuat key


502{ "error": "Upstream gagal" }Penyedia email tidak merespons


503{ "error": "API_SECRET belum diisi di server" }Server belum dikonfigurasi
